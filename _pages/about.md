# 안녕하세요, libok03입니다.

로봇, 자율주행, 제어, 강화학습을 공부하고 구현하면서 배운 내용을 기록합니다. 이 블로그는 완성된 결과물만 올리는 포트폴리오라기보다, 문제를 만나고 고치고 다시 설계하는 과정을 남기는 작업 노트에 가깝습니다.

## 주로 다루는 것

- ROS2 기반 자율주행과 로봇 매니퓰레이션
- ERP42, UR5e, Robotiq, Gazebo, MoveIt2 실험
- PPO, DQN, Q-Learning 같은 강화학습 실험
- 프로젝트를 진행하며 만난 오류와 해결 과정
